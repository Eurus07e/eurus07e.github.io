1. 树与森林的基本概念

概念 定义
结点的度 结点的子女个数
树的度 所有结点的度的最大值
叶结点 度为 0 的结点
分支结点 度不为 0 的结点
兄弟结点 具有相同父结点
结点深度 结点所在层次
结点高度 以该结点为根的子树高度
树的高度、深度 最大层次，二者相等
有序树 子树之间有次序
无序树 子树之间不强调次序
森林 若干棵互不相交的树组成的集合
  • 非空树中，根没有父结点，其余结点各有一个父结点。
  • 根到任一结点的路径唯一。
  • 删除根后，剩余子树数等于根的度。

计数关系

设总结点数为 n，度为 i 的结点数为 ni。

项目 公式
非空树的边数 n−1
所有结点的度之和 n−1
含 n 个结点、m 棵非空树的森林边数 n−m
普通树的叶结点数 n0=1+∑i≥1(i−1)ni

2. 二叉树

定义与基本性质

  • 每个结点最多有两个子女。
  • 左、右子树有区别，不能任意交换。
  • 只有一个子女时，也必须区分左子女和右子女。
  • 二叉树的度不一定为 2，也可以为 0 或 1。
  • 五种基本形态：空树、仅根、仅左子树、仅右子树、左右子树均存在。
项目 公式
第 i 层最多结点数 2i−1
高度为 h 时最少结点数 h
高度为 h 时最多结点数 2h−1
n 个结点的高度范围 ⌈log2⁡(n+1)⌉≤h≤n
结点数关系 n=n0+n1+n2
边数关系 n−1=n1+2n2
叶结点与度为 2 的结点 n0=n2+1

满二叉树与完全二叉树

  • 满二叉树：每一层都达到最大结点数。
  • 完全二叉树：除最后一层外各层均满，最后一层从左向右连续排列。
  • 满二叉树一定是完全二叉树，反之不成立。
  • 没有度为 1 的结点，不足以说明是满二叉树。
项目 满二叉树 完全二叉树
高度 h h=⌈log2⁡(n+1)⌉=⌊log2⁡n⌋+1
总结点数 2h−1 2h−1≤n≤2h−1
叶结点数 2h−1 ⌈n/2⌉
非叶结点数 2h−1−1 ⌊n/2⌋
度为 1 的结点数 0 n 偶数时为 1，奇数时为 0
度为 2 的结点数 2h−1−1 ⌊(n−1)/2⌋
最后一层结点数 2h−1 n−(2h−1−1)
  • 完全二叉树至多有一个度为 1 的结点，且只有左子女。
  • 完全二叉树的叶结点可能分布在最后两层。
  • 叶结点数不一定等于最后一层结点数。

完全二叉树的编号关系

以下子女下标均须落在有效范围内。

关系 从 1 开始编号 从 0 开始编号
根 1 0
父结点 ⌊i/2⌋, i>1 ⌊(i−1)/2⌋, i>0
左子女 2i 2i+1
右子女 2i+1 2i+2
第一个叶结点 ⌊n/2⌋+1 ⌊n/2⌋
最后一个非叶结点 ⌊n/2⌋ ⌊n/2⌋−1

从 1 开始编号时：

  • 偶数编号为左子女。
  • 奇数编号的非根结点为右子女。
  • 右子女的左兄弟为 i−1。
  • 左子女的右兄弟若存在，编号为 i+1。

3. 二叉树的存储与表示

存储结构

结构 特点
顺序存储 适合完全二叉树；一般二叉树可能存在大量空位置
二叉链表 数据域＋左子女指针＋右子女指针
三叉链表 在二叉链表基础上增加父指针
静态链表 用数组下标代替指针表示关系
  • 只有右子女的单支树，从 0 开始的下标为 0,2,6,14,30,…。
  • 高度为 h 的右单支树，顺序表示需覆盖 2h−1 个数组位置。

空指针域

结构 空指针域数
n 个结点的二叉链表 n+1
n 个结点的三叉链表 n+2
每个结点设置 d 个子女指针的普通树 nd−(n−1)=n(d−1)+1

广义表表示

  • A(B,C)：A 的左、右子树分别为 B、C。
  • A(B,)：只有左子树。
  • A(,B)：只有右子树，逗号不能省略。
  • 叶结点可直接写为 A。
  • 课件中末尾的 # 表示整个输入结束。

带空标记的前序表示

  • 用 @ 等特殊值表示空子树。
  • 完整的带空标记前序序列可以唯一确定二叉树。
  • n 个实际结点对应 n+1 个空标记。
  • 序列总长度为 2n+1。
  • 空子树标记与整个输入的结束标记含义不同。

4. 二叉树遍历与还原

遍历次序

记根为 V、左子树为 L、右子树为 R。

遍历 次序 常用辅助结构
前序 VLR 栈
中序 LVR 栈
后序 LRV 栈＋状态信息
层次序 从上到下、同层从左到右 队列
  • 遍历要求每个结点访问一次且仅一次。
  • 四种遍历时间复杂度均为 O(n)。
  • 常见深度优先实现辅助空间为 O(h)。
  • 层次遍历辅助空间为 O(w)，w 为最大层宽。
  • 以上空间不计存储输出序列的空间。

遍历序列还原

前提：结点标识互不相同。

已知序列 是否能唯一还原
前序＋中序 能
中序＋后序 能
前序＋后序 不一定
只有普通前序 不一定
带完整空标记的前序 能
  • 前序首项是根。
  • 后序末项是根。
  • 中序中根的位置划分左右子树。
  • 前序 AB、后序 BA：B 可以是 A 的左子女，也可以是右子女。

遍历的应用

操作 课件采用的思路
计算结点数 后序：左子树数＋右子树数＋1
计算高度 后序：左右子树高度最大值＋1
删除整棵树 后序：先删子树，再删根
复制二叉树 前序：先复制根，再复制子树
根据带空标记序列建树 前序
输出广义表 前序＋括号、逗号

5. 线索二叉树

定义与标志

  • 线索记录某一种遍历顺序下的前驱、后继。
  • 可额外增加前驱、后继指针，也可利用原来的空子女指针。
  • 线索化不改变原有的真实父子关系。
标志 含义
ltag == 0 左指针指向真实左子女
ltag == 1 左指针为前驱线索
rtag == 0 右指针指向真实右子女
rtag == 1 右指针为后继线索

中序线索

查找对象 方法
子树中序第一个结点 沿真实左子女走到尽头
子树中序最后一个结点 沿真实右子女走到尽头
当前结点的前驱 有左线索则直接取；否则取左子树中序最后一个结点
当前结点的后继 有右线索则直接取；否则取右子树中序第一个结点
  • 最左下、最右下结点不一定是叶结点。
  • 无头结点时，中序第一个结点的前驱为 NULL。
  • 无头结点时，中序最后一个结点的后继为 NULL。
  • 非空、无头结点的中序线索树：线索域 n+1 个，非空线索 n−1 条。

中序线索化

  • 按中序访问结点。
  • pre 记录刚访问过的结点。
  • 当前结点左指针为空：建立当前结点的前驱线索。
  • pre 的右指针为空：建立 pre 的后继线索。
  • 更新 pre。
  • 最后处理中序最后一个结点的后继及标志。

前序、后序线索

查找对象 规则
前序后继 有真实左子女则取左子女；否则取右指针
前序前驱 有左线索则直接取；否则结合父结点判断
后序前驱 有左线索则直接取；否则优先取真实右子女，没有则取左子女
后序后继 有右线索则直接取；否则结合父结点判断

前序前驱需要父结点时：

  • 当前结点是左子女，或父结点没有左子树：前驱为父结点。
  • 否则：前驱为父结点左子树中前序最后一个结点。
  • 根没有前序前驱。

后序后继需要父结点时：

  • 当前结点是右子女，或父结点没有右子树：后继为父结点。
  • 否则：后继为父结点右子树中后序第一个结点。
  • 根没有后序后继。

不给根指针，寻找中序线索树结点的父结点

  • 若目标是左子女：其子树最右结点的中序后继为父结点。
  • 若目标是右子女：其子树最左结点的中序前驱为父结点。
  • 检查候选结点是否通过对应子女指针指回目标。
  • 若目标是根，两侧边界线索均为空。

6. 普通树、森林及其二叉树表示

普通树的存储

表示方法 特点
广义表 用括号表示子树层次
父指针表示 每个结点记录父结点，查找父结点方便
子女指针表示 每个结点固定设置 d 个子女指针，可能浪费空间
子女链表表示 每个结点的子女组成链表
子女—兄弟表示 第一个子女＋下一个兄弟

子女—兄弟表示

  • 左指针：第一个子女。
  • 右指针：下一个兄弟。
  • 查找所有子女：先到第一个子女，再沿兄弟链扫描。

树、森林与二叉树转换

  • 单棵树转换后，根没有右子女。
  • 森林转换后，各棵树的根通过右指针连接。
  • 二叉树根的左子树：第一棵树根的子树森林。
  • 二叉树根的右子树：除第一棵树以外的其余森林。
  • 从二叉树根连续沿右子女走，链上的结点数等于森林的树数。
  • 转换保持结点数，不保证保持高度。
  • 原树的叶结点转换后没有左子女，但可能有右子女。

遍历对应关系

树或森林的遍历 对应二叉树的遍历
先根遍历 前序遍历
后根遍历 中序遍历

森林层次遍历：

  • 先访问所有根，再逐层访问子女。
  • 可以将所有根依次入队。
  • 也可以只入队每条兄弟链的起点，出队后遍历整条兄弟链。
  • 不能将“下一个兄弟”误当作下一层的右子女。

7. 堆与优先级队列

基本性质

  • 堆在结构上是完全二叉树。
  • 最小堆：父结点值不大于子女值，堆顶为最小值。
  • 最大堆：父结点值不小于子女值，堆顶为最大值。
  • 兄弟之间没有固定大小关系。
  • 堆数组不要求整体有序。
  • 堆不是二叉搜索树。
  • 优先级队列每次取出优先权最高的元素，不按普通队列的先入先出顺序。

从 0 开始存储时：

parent(i)=⌊i−12⌋,left(i)=2i+1,right(i)=2i+2

操作与复杂度

操作 时间复杂度
取堆顶 O(1)
向上调整 最坏 O(log⁡n)
向下调整 最坏 O(log⁡n)
插入 最坏 O(log⁡n)，不计扩容
删除堆顶 最坏 O(log⁡n)
逐个插入建堆 最坏 O(nlog⁡n)
自底向上筛选建堆 紧确界 O(n)

课件第 177 页将建堆标为 O(nlog⁡n)；对自底向上筛选法，这是宽松上界。

边界检查

  • 空堆取值、删除失败时，不应修改输出参数。
  • 满堆插入失败时，不应修改堆。
  • 删除最后一个元素后，不应继续访问已空的数组。
  • 清空只移除有效元素，不改变容量上限。
  • 重复值允许存在，父子相等时不必交换。

8. 路径长度与 Huffman 树

路径长度

名称 定义
两结点间路径长度 路径上的边数
结点到根的路径长度 结点层次减 1
外部路径长度 EPL 所有叶结点到根的路径长度之和
内部路径长度 IPL 所有非叶结点到根的路径长度之和
树的路径长度 PL PL=EPL+IPL
带权路径长度 WPL ∑iwili，只对带权叶结点求和
  • 根到自身的路径长度为 0。
  • 固定 n 个结点时：
PLmin=∑i=1n⌊log2⁡i⌋
  • 完全二叉树可以达到最小 PL。
  • 最小 PL 与最小 WPL 是不同问题。

扩充二叉树

按本课件定义：

  • 外结点为叶结点，度为 0。
  • 内结点度为 2。
  • 不存在度为 1 的结点。

有 k 个外结点时：

项目 数量
外结点 k
内结点 k−1
总结点 2k−1

Huffman 树

  • 对给定叶权值集合，WPL 最小的扩充二叉树。
  • 每次合并当前根权值最小的两棵树。
  • 新根权值等于两棵子树根权值之和。
  • 用 k 个权值构造时，合并 k−1 次。
  • 原始权值位于叶结点。
  • 根权值为全部原始权值之和。
  • 无度为 1 的结点。
  • 不一定是完全二叉树，也不一定是本课件定义的满二叉树。
  • 树形可以不唯一，但最优 WPL 相同。
  • 较大权值的叶结点不会比较小权值的叶结点更深；深度可以相同。
WPL=∑iwili=各次合并产生的新权值之和

9. Huffman 编码

  • 字符对应叶结点。
  • 课件约定左分支为 0，右分支为 1。
  • 根到叶的分支序列就是字符编码。
  • 码长等于对应叶结点到根的路径长度。
  • Huffman 编码是前缀编码。
  • 前缀编码：任一码字都不是另一个码字的前缀。
  • 编码可能不唯一，但最优平均码长相同。
  • Huffman 编码不一定比定长编码严格更短，也可能相同。
计算项目 公式
总编码位数，wi 为出现次数 ∑iwili=WPL
平均码长，pi 为出现概率 ∑ipili
由频数计算平均码长 WPL/∑iwi
k≥2 种字符的最短二进制定长码长 ⌈log2⁡k⌉

前缀性质示例：

  • {0, 10, 11}：满足。
  • {0, 01, 11}：不满足，0 是 01 的前缀。

解码规则：

  • 从根按比特选择分支。
  • 到叶结点时输出对应字符。
  • 回到根，继续处理后续比特。

10. 代码题清单与关键检查点

二叉树基本操作

题目 关键点
求结点数 空树为 0；左右子树结点数之和加 1
求高度 空树为 0；左右子树高度最大值加 1
查找父结点 检查当前结点的两个子女，再搜索子树
删除整棵树 后序删除，根最后释放
复制二叉树 新建当前结点，再分别复制左右子树
广义表建树 栈保存父结点；括号控制层次；逗号切换左右子树
带空标记前序建树 空标记返回空指针；非空时依次建立根、左、右
输出广义表 叶结点不加括号；只有右子树时保留逗号

非递归遍历

题目 关键点
前序遍历 访问当前结点；保存待处理右子树；继续向左
中序遍历 左链入栈；退栈时访问；转向右子树
后序遍历 单栈＋L/R 状态，或单栈＋last
层次遍历 队列；按左、右顺序加入子女

后序遍历的 last 写法：

  • last 表示最近访问完的结点。
  • 右子树为空，或 last == 当前结点的右子女，才可访问当前结点。
  • 否则先处理右子树。
  • 访问当前结点后，将遍历指针置空，继续检查栈顶祖先。

线索树与森林

题目 关键点
建立中序线索 中序访问；维护 pre；处理首尾线索
中序线索树遍历 不用栈；通过子女标志和后继线索前进
不给根指针找父结点 检查目标子树两端的线索及候选父子关系
森林先根遍历 对应二叉树前序
森林后根遍历 对应二叉树中序
森林层次遍历 正确处理多个根与兄弟链

堆

题目 关键点
siftDown 与较小子女比较；处理只有左子女的情况
siftUp 与父结点比较；交换后继续向上
筛选法建堆 从最后一个非叶结点开始，向根依次下调
插入法建堆 依次扩大有效前缀，对新元素上调
插入 判满；追加末尾；上调
删除堆顶 判空；保存堆顶；末尾补根；删除末尾；下调
取堆顶 判空；只读取，不删除
清空 清除有效元素，保留容量上限

下标与 C++ 边界：

  • 最后有效下标为 m 时，左子女存在条件为 2 * start + 1 <= m。
  • 元素个数为 n 时，最后非叶结点为 n / 2 - 1。
  • erase(first, last) 删除左闭右开区间 [first, last)。
  • 删除末尾元素可用 pop_back()。
  • 清空 vector 可用 clear()。

Huffman

题目 关键点
构造 Huffman 树 最小堆维护森林；反复取两个最小权值并合并
计算 WPL 累加叶权值×深度，或累加各次合并权值

前缀、中缀与后缀表达式

1. 基本概念

以 (A+B)*(C-D) 为例：

类型 表达式 特点
前缀表达式 * + A B - C D 运算符在操作数前
中缀表达式 (A+B)*(C-D) 运算符在操作数中间
后缀表达式 A B + C D - * 运算符在操作数后
  • 前缀表达式：波兰表达式（Polish Notation）。
  • 后缀表达式：逆波兰表达式（Reverse Polish Notation）。
  • 前缀、后缀表达式在运算符元数确定时无需括号。
  • 中缀表达式需要考虑运算符优先级、结合性和括号。

2. 表达式树

对于 (A+B)*(C-D)：

       *
      / \
     +   -
    / \ / \
   A  B C  D
遍历方式 对应表达式 遍历顺序
前序遍历 前缀 根→左→右
中序遍历 中缀 左→根→右
后序遍历 后缀 左→右→根

注意：中序遍历输出时需要根据运算优先级和结合性补充括号。

3. 六种表达式转换

3.1 中缀 → 前缀

  • 构造表达式树，进行前序遍历。
  • 根运算符在最前面。
中缀：(A+B)*(C-D)
前缀：* + A B - C D

3.2 中缀 → 后缀

  • 构造表达式树，进行后序遍历。
  • 根运算符在最后面。
中缀：(A+B)*(C-D)
后缀：A B + C D - *

3.3 前缀 → 中缀

从右向左扫描，使用栈。

  1. 遇到操作数：入栈。
  2. 遇到运算符：第一次弹出左操作数，第二次弹出右操作数。
  3. 组合为 (左 运算符 右)，结果入栈。
前缀：* + A B - C D
中缀：(A+B)*(C-D)

3.4 后缀 → 中缀

从左向右扫描，使用栈。

  1. 遇到操作数：入栈。
  2. 遇到运算符：第一次弹出右操作数，第二次弹出左操作数。
  3. 组合为 (左 运算符 右)，结果入栈。
后缀：A B + C D - *
中缀：(A+B)*(C-D)

3.5 前缀 → 后缀

从右向左扫描，使用栈。

  1. 遇到操作数：入栈。
  2. 遇到运算符：依次弹出左、右子表达式。
  3. 组合为 左 右 运算符，结果入栈。
前缀：* + A B - C D
后缀：A B + C D - *

3.6 后缀 → 前缀

从左向右扫描，使用栈。

  1. 遇到操作数：入栈。
  2. 遇到运算符：依次弹出右、左子表达式。
  3. 组合为 运算符 左 右，结果入栈。
后缀：A B + C D - *
前缀：* + A B - C D

4. 前缀与后缀表达式求值

4.1 前缀表达式求值

从右向左扫描，使用操作数栈。

  1. 遇到数字：入栈。
  2. 遇到运算符：弹出两个数字。
  3. 第一次弹出的是左操作数，第二次弹出的是右操作数。
  4. 运算结果入栈。

例如：

前缀：- * + 2 3 4 / 8 2

计算：
(2+3)*4 - 8/2
= 20-4
= 16

扫描过程（栈顶在右）：

扫描元素 操作 栈
2 入栈 [2]
8 入栈 [2,8]
/ 8/2=4 [4]
4 入栈 [4,4]
3 入栈 [4,4,3]
2 入栈 [4,4,3,2]
+ 2+3=5 [4,4,5]
* 5*4=20 [4,20]
- 20-4=16 [16]

4.2 后缀表达式求值

从左向右扫描，使用操作数栈。

  1. 遇到数字：入栈。
  2. 遇到运算符：弹出两个数字。
  3. 第一次弹出的是右操作数，第二次弹出的是左操作数。
  4. 运算结果入栈。

例如：

后缀：2 3 + 4 * 8 2 / -

计算：
(2+3)*4 - 8/2
= 16

5. 考试速查表

操作 扫描方向 规则
中缀 → 前缀 表达式树前序 根左右
中缀 → 后缀 表达式树后序 左右根
前缀 → 中缀 右→左 (左右运算)
后缀 → 中缀 左→右 (左右运算)
前缀 → 后缀 右→左 左右运算符
后缀 → 前缀 左→右 运算符左右
前缀求值 右→左 先弹左，后弹右
后缀求值 左→右 先弹右，后弹左

6. 易错点

  • 前缀从右向左处理，后缀从左向右处理。
  • 前缀先弹出左操作数，后缀先弹出右操作数。
  • 减法、除法不能交换左右操作数。
  • * / 优先级高于 + -。
  • 同优先级的 + - * / 通常按左结合处理。
  • 括号优先级最高。
  • 遇到多位数时，应按完整数字分词，不能逐位处理。
  • 对有效的二元运算前缀、后缀表达式，求值结束时栈中应恰好剩余一个结果。

例如：

中缀：A-B/C
前缀：- A / B C
后缀：A B C / -

中缀：(A-B)/C
前缀：/ - A B C
后缀：A B - C /

核心口诀：

  • 前缀：根左右，右往左扫，先弹左。
  • 后缀：左右根，左往右扫，先弹右。
  • 中缀转换：先确定运算顺序，再进行相应遍历。

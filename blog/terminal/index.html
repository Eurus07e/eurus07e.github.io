一、终端基础命令

命令 作用
pwd 显示当前所在目录
ls 查看当前目录下的文件
ls -l 以详细列表形式查看文件
ls -a 显示隐藏文件
ls -lh 以易读大小显示文件信息
cd 文件夹名 进入指定文件夹
cd .. 返回上一级目录
cd ~ 返回用户主目录
clear 清屏
open . 在 Finder 中打开当前目录

二、文件与文件夹操作

命令 作用
mkdir dir 新建文件夹 dir
touch a.txt 新建空文件 a.txt
cp a.txt b.txt 复制文件
cp -r dir1 dir2 复制文件夹
mv old.txt new.txt 重命名文件
mv a.txt dir/ 移动文件到指定文件夹
rm a.txt 删除文件
rm -r dir 删除文件夹
rm -rf dir 强制删除文件夹，需谨慎使用
open a.pdf 用默认应用打开文件

三、查看文件内容

命令 作用
cat a.txt 一次性显示整个文件内容
less a.txt 分页查看文件内容
head a.txt 查看文件前 10 行
tail a.txt 查看文件后 10 行
tail -f log.txt 实时查看日志文件更新
grep "hello" a.txt 在文件中搜索 hello
grep -r "hello" . 在当前目录递归搜索 hello

四、路径与环境变量

命令 作用
which python3 查看 python3 的路径
which g++ 查看 g++ 的路径
echo $PATH 查看环境变量 PATH
export PATH=路径:$PATH 临时添加环境变量路径
source ~/.zshrc 重新加载 zsh 配置文件
nano ~/.zshrc 编辑 zsh 配置文件

五、编译与运行 C++

命令 作用
g++ main.cpp 编译 main.cpp，默认生成 a.out
./a.out 运行默认生成的程序
g++ main.cpp -o main 编译并指定输出文件名为 main
./main 运行当前目录下的 main 程序
g++ main.cpp -std=c++17 -o main 使用 C++17 标准编译
g++ main.cpp -Wall -Wextra -o main 开启常用警告信息编译
clang++ main.cpp -std=c++17 -o main 使用 clang++ 编译 C++ 程序

六、Python 常用命令

命令 作用
python3 --version 查看 Python 版本
python3 main.py 运行 Python 文件
python3 -m venv .venv 创建虚拟环境
source .venv/bin/activate 激活虚拟环境
deactivate 退出虚拟环境
pip install package 安装 Python 包
pip list 查看已安装包
pip freeze > requirements.txt 导出依赖列表
pip install -r requirements.txt 按依赖文件安装包

七、Git 基础命令

命令 作用
git init 在当前目录初始化 Git 仓库
git status 查看仓库当前状态
git add . 添加所有改动到暂存区
git add file.cpp 添加指定文件到暂存区
git commit -m "message" 提交代码并写提交说明
git log 查看完整提交记录
git log --oneline 查看简洁提交记录
git diff 查看工作区尚未暂存的改动
git diff --staged 查看已暂存但未提交的改动

八、Git 分支命令

命令 作用
git branch 查看本地分支
git branch new-branch 创建新分支
git checkout 分支名 切换到指定分支
git checkout -b new-branch 创建并切换到新分支
git switch 分支名 切换分支，新版本推荐用法
git switch -c new-branch 创建并切换到新分支
git merge 分支名 将指定分支合并到当前分支
git branch -d 分支名 删除本地分支

九、GitHub 远程仓库命令

命令 作用
git clone 仓库地址 克隆 GitHub 远程仓库到本地
git remote -v 查看当前绑定的远程仓库地址
git remote add origin 仓库地址 绑定远程仓库并命名为 origin
git push -u origin main 第一次推送 main 分支到 GitHub
git push 推送本地提交到远程仓库
git pull 拉取远程更新并合并到本地
git fetch 只拉取远程信息，不自动合并
git pull origin main 从远程 main 分支拉取更新

十、GitHub 常见工作流

命令 作用
git clone url 从 GitHub 下载项目
cd project 进入项目目录
git status 查看当前是否有改动
git add . 添加所有修改
git commit -m "feat: add feature" 提交本地修改
git push 推送到 GitHub
git pull 提交前先同步远程更新

十一、Git 配置命令

命令 作用
git config --global user.name "Your Name" 设置 Git 用户名
git config --global user.email "email@example.com" 设置 Git 邮箱
git config --global --list 查看全局 Git 配置
git config user.name 查看当前仓库用户名
git config user.email 查看当前仓库邮箱

十二、Git 撤销与恢复

命令 作用
git restore file.cpp 丢弃工作区中指定文件的改动
git restore . 丢弃当前目录下所有未暂存改动
git restore --staged file.cpp 取消暂存指定文件
git reset --soft HEAD~1 撤销最近一次提交，但保留改动
git reset --hard HEAD~1 删除最近一次提交和改动，慎用
git revert 提交ID 生成一次新的提交来撤销旧提交

十三、进程与系统信息

命令 作用
top 查看系统进程与资源占用
ps aux 查看所有进程
ps aux | grep name 搜索指定进程
kill PID 结束指定进程
kill -9 PID 强制结束指定进程
df -h 查看磁盘空间
du -sh dir 查看文件夹大小
whoami 查看当前用户名
uname -a 查看系统信息

十四、网络与远程连接

命令 作用
ping baidu.com 测试网络连通性
curl url 请求网页或接口内容
curl -O url 下载文件并保留原文件名
wget url 下载文件，需额外安装 wget
ssh user@host 连接远程服务器
scp file user@host:path 复制文件到远程服务器
scp user@host:path file 从远程服务器复制文件到本地

十五、最推荐优先掌握

命令 作用
pwd 看自己在哪个目录

cd 切换目录
mkdir 新建文件夹

rm 删除文件
cp 复制文件
mv 移动或重命名文件
open . 用 Finder 打开当前目录
g++ main.cpp -std=c++17 -o main 编译 C++ 程序
./main 运行程序
git status 查看 Git 状态
git add . 添加所有改动
git commit -m "message" 提交代码
git push 推送代码到 GitHub
git pull 拉取 GitHub 最新代码

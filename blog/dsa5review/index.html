第四章 数组、串与广义表 Cheat Sheet

4.1 一维数组与多维数组

1. 基本概念

  • 一维数组：线性结构，元素由下标唯一确定。
  • 多维数组：线性结构的扩展，属于非线性结构。
  • 静态数组：编译期确定大小，空间不可扩充。
  • 动态数组：运行期分配空间，使用 new[] 和 delete[]。
  • C/C++ 原生多维数组采用行优先连续存储。
  • 使用 int** 逐行动态分配的二维数组不一定连续存储。

2. 二维数组地址映射

设 A[n][m]，首地址为 a，每个元素占 l 字节，下标从 0 开始。

  • 行优先：
LOC(i,j)=a+(im+j)l
  • 列优先：
LOC(i,j)=a+(jn+i)l

记忆：行优先乘列数，列优先乘行数。

3. 三维数组地址映射

设 A[m1][m2][m3]。

  • 页／行／列顺序（最后一维变化最快）：
LOC(i,j,k)=a+(im2m3+jm3+k)l
  • 列／行／页顺序（第一维变化最快）：
LOC(i,j,k)=a+(km1m2+jm1+i)l

4. n 维数组

按行优先存储：

LOC(i1,…,in)=a+l∑j=1n(ij∏k=j+1nmk)

约定空乘积为 1。

  • 最后一维下标变化最快。
  • 每维下标的系数为其后各维大小的乘积。
  • 地址计算最后乘元素字节数。

4.2 特殊矩阵

1. 对称矩阵压缩存储

对称矩阵满足：

aij=aji

只存储上三角或下三角（包括主对角线）。

存储元素数：

n(n+1)2

设一维数组 B 下标从 0 开始。

存储区域 顺序 映射公式 k
下三角 行优先 i(i+1)2+j
下三角 列优先 (2n−j+1)j2+i−j
上三角 行优先 (2n−i−1)i2+j
上三角 列优先 j(j+1)2+i
  • 上三角要求 i≤j。
  • 下三角要求 i≥j。
  • 对称矩阵中不在存储区域的元素，交换 i,j 后计算。
  • 逆映射：先确定所在行或列，再计算该行或列内的偏移量。

2. 三对角矩阵

允许出现非零元素的条件：

|i−j|≤1

三条对角线元素总数：

3n−2

按行优先压缩存储：

k=2i+j

逆映射：

i=⌊k+13⌋j=k−2i

逆映射后检查下标是否合法。

3. 带状矩阵

  • 带宽 b：主对角线上、下各有 b 条对角线，不包括主对角线本身。
  • 带状区域满足：
|i−j|≤b

采用 PPT 的过渡矩阵方法：

A′ 的大小=n×(2b+1)

原矩阵到过渡矩阵：

t=i,s=j−i+b

压缩下标：

k=(2b+1)i+j−i+b

等价于：

k=2bi+j+b

反向映射：

i=⌊k2b+1⌋s=kmod(2b+1)j=s+i−b

额外填充零元素数（n≥2b+1）：

b(b+1)

易错：

  • 过渡矩阵的列下标是 j - i + b，不能直接使用 j。
  • 逆映射必须检查 0≤i,j<n。
  • 例如 8×8、b=2、B[34]：
(i,j)=(6,8)
  • j=8 越界，因此对应填充零元素，不对应原矩阵有效位置。

4.3 稀疏矩阵

1. 基本概念

设矩阵大小为 m×n，非零元素个数为 s。

稀疏因子：

e=smn
  • PPT 通常以 e≤0.05 作为稀疏矩阵的判断标准。
  • 稀疏矩阵通常只存储非零元素。
  • 主要表示方法：三元组表、正交链表。

2. 三元组表示

struct Triple {
    int row, col, value;
};
  • 每个三元组存储行号、列号、元素值。
  • 按行优先排列。
  • 行号相同时按列号递增排列。
  • 转置：交换每个三元组的行号、列号，并重新排序。

3. 普通转置算法

  • 遍历原矩阵每一列。
  • 每列扫描整个三元组表。
  • 原矩阵有 n 列、t 个非零元素：
T=O(nt)

4. 快速转置算法

辅助数组：

  • rowSize：原矩阵每列的非零元素个数。
  • rowStart：转置矩阵对应行在三元组表中的起始位置。

也可以使用一个偏移数组完成统计和定位。

void FastTranspose(
    int cols,
    const vector<Triple>& a,
    vector<Triple>& b
) {
    vector<int> pos(cols + 1, 0);
    b.resize(a.size());

    for (const auto& x : a)
        pos[x.col + 1]++;

    for (int i = 1; i <= cols; i++)
        pos[i] += pos[i - 1];

    for (const auto& x : a)
        b[pos[x.col]++] = {x.col, x.row, x.value};
}
  • 先统计每列数量。
  • 再计算前缀和。
  • 最后直接放到目标位置。

复杂度：

T=O(n+t),S辅助=O(n)

5. 稀疏矩阵相加

前提：两个矩阵行数、列数对应相等。

利用行优先三元组表的双指针合并：

index=i×Cols+j
  • indexA < indexB：复制 A 当前元素，A 指针前进。
  • indexA > indexB：复制 B 当前元素，B 指针前进。
  • 相等：两值相加，若结果非零则保存，两个指针均前进。
  • 主循环结束后，复制未处理的剩余元素。

易错代码：

while (i < a.size())
    c.push_back(a[i++]);

while (j < b.size())
    c.push_back(b[j++]);
  • 必须使用 while，不能只用 if。
  • 处理 B 的剩余元素时必须访问 b[j]，不能误写 a[j]。
  • 相加结果为 0 时不加入三元组表。

复杂度：

O(tA+tB)

6. 正交链表（十字链表）

非零元素结点：

  • row：行号。
  • col：列号。
  • value：元素值。
  • right：同行下一个非零元素结点。
  • down：同列下一个非零元素结点。

附加头结点：

  • right：对应行链表的第一个结点。
  • down：对应列链表的第一个结点。
  • next：下一个附加头结点。

特点：

  • 同时维护行链表和列链表。
  • 插入、删除主要修改指针。
  • 适合非零元素频繁变化的矩阵运算。

4.4 字符串

1. 基本概念

  • 串：有限字符序列。
  • 串长：字符个数。
  • 空串 ""：长度为 0。
  • 空白串 " "：长度为 1。
  • 子串：主串中连续字符组成的序列。
  • 空串是任意串的子串。
  • 任意串是自身的子串。
  • 子串出现允许重叠。

例如：

S = "ababa"
T = "aba"

T 出现两次，起始下标分别为 0、2。

2. C 字符串函数

函数 作用
strlen(s) 获取长度，不包括 \0
strcpy(a,b) 复制 b 到 a
strncpy(a,b,n) 最多复制 n 个字符
strcat(a,b) 将 b 连接到 a 后面
strncat(a,b,n) 最多追加 n 个字符
strcmp(a,b) 字典序比较

注意：

  • C 字符串以 \0 结束。
  • 分配空间至少为字符串长度加 1。
  • strcpy、strcat 要求目标空间足够。
  • strcat 的源、目标内存区域不得重叠。
  • strncpy 不保证始终添加终止符。

3. AString 类

主要成员：

char* ch;
int curLength;
int maxSize;

主要操作：

操作 含义
S(pos,len) 提取子串
S[i] 取字符
S == T 判断相等
S != T 判断不等
!S 判断空串
S = T 赋值
S += T 连接

提取子串：

  • pos 从 0 开始。
  • 提取长度超过剩余字符数时，按 PPT 算法截取到串尾。
len=min(len,curLength−pos)

示例：

AString S("university");
AString T = S(7, 5); // "ity"

4. 拷贝构造、赋值与动态内存

深拷贝：

ch = new char[ob.maxSize + 1];
strcpy(ch, ob.ch);

禁止将拥有动态数组的两个对象简单地共享同一个 char*，否则析构时可能重复释放。

赋值运算符：

  • 检查自身赋值。
  • 正确分配并复制字符数组。
  • 更新 curLength 和 maxSize。
  • 释放旧数组时使用 delete[]。
  • 更稳妥的实现应先确保新空间分配成功，再释放旧空间。

易错：字符串自身连接

AString s("abc");
s += s;

如果 ob 引用当前对象，那么：

strcat(ch, ob.ch);

可能等价于：

strcat(ch, ch);

产生源、目标重叠的未定义行为。

对于 PPT 第 93–94 页的实现，可将该行改为：

strcat(ch, (&ob == this) ? temp : ob.ch);

其中 temp 指向连接前的旧字符数组。

自行处理自身连接时特别检查：

  • ch 是指针，不能写 ch.curLength。
  • 字符数组需要为 \0 多分配 1 字节。
  • 使用 delete[]，不能使用 delete。
  • 修改后同步更新 curLength、maxSize。
  • 避免源、目标内存重叠。

5. BF 模式匹配

  • 从主串的每个可能起始位置逐个比较。
  • 失配后重新选择起始位置。
  • 最坏比较次数：
(n−m+1)m
  • 最坏时间复杂度：
O(nm)

6. KMP（已掌握，跳过后续专项复习）

  • next 只依赖模式串。
  • next[0] = -1。
  • 对 j>0，next[j] 为 P[0...j-1] 最长相等真前后缀的长度。
  • 失配时模式串指针按 next 回退，主串指针不回退。
  • 匹配成功返回起始下标，否则返回 -1。
  • 预处理加匹配总复杂度：
O(n+m)

示例：

P:     a  b  a  b  a  c  a
next: -1  0  0  1  2  3  0

4.5 广义表

1. 基本概念

广义表元素可以是：

  • 原子。
  • 子表。

对于非空广义表：

  • head(L)：第一个表元素。
  • tail(L)：除第一个表元素外，其余元素组成的表。
  • 表尾始终是一个广义表。
  • 空表的表头和表尾不存在。

例：

L = (a,(b,c),((d,e)),f)

head(L)             = a
tail(L)             = ((b,c),((d,e)),f)
head(tail(tail(L))) = ((d,e))
tail(head(tail(L))) = (c)

易错：

head(((a,b))) = (a,b)
tail(((a,b))) = ()

head((())) = ()
tail((())) = ()

() 和 (()) 不相同。

2. 长度与深度

  • 长度：最外层表元素的个数。
  • 深度：最大括号嵌套层数。
  • 原子深度：0。
  • 空表深度：1。
  • 递归表的深度可以为无穷大。

递推规则：

Depth(L)={1,L 为空表0,L 为原子1+maxiDepth(ai),其他

示例：

L = (a,((b,c),(d,(e,f))),(),g)
  • 长度 = 4。
  • 深度 = 4。

递归表：

F = (h,F)
  • 长度 = 2。
  • 深度 = 无穷大。

3. 广义表结点

struct Node {
    int utype;

    union {
        int ref;
        char value;
        Node* hlink;
    } info;

    Node* tlink;
};
utype 结点类型 info
0 附加头结点 ref
1 原子结点 value
2 子表结点 hlink
  • hlink：指向子表附加头结点。
  • 普通结点的 tlink：指向同层下一个结点。
  • 附加头结点的 tlink：指向本表第一个元素。
  • 空表的附加头结点 tlink == nullptr。
  • 每个子表都有自己的附加头结点。

4. 广义表复制

  • 递归复制当前结点。
  • utype == 1：复制原子值。
  • utype == 2：递归复制 hlink 指向的子表。
  • 递归复制 tlink 指向的同层后继结点。

注意：

  • 普通递归复制无法保留共享子表关系，会重复复制共享子表。
  • 对含循环引用的递归表，普通递归复制可能无限递归、栈溢出。

5. 广义表深度算法

核心代码：

int Depth(Node* ls) {
    if (ls->tlink == nullptr)
        return 1;

    int maxDepth = 0;

    for (Node* p = ls->tlink;
         p != nullptr;
         p = p->tlink) {

        if (p->utype == 2) {
            int d = Depth(p->info.hlink);
            if (d > maxDepth)
                maxDepth = d;
        }
    }

    return maxDepth + 1;
}
  • 横向遍历同层结点。
  • 遇到子表时向下递归。
  • 取所有子表的最大深度加 1。
  • 适用于非递归广义表。

6. 原子结点删除

  • 删除目标原子时需要更新链表指针。
  • 连续出现多个目标原子，应使用 while 删除。
  • 遇到子表时递归进入 hlink。
  • 再通过 tlink 继续处理当前层后续结点。
  • 删除原子后，原来的子表结构保留。

易错：while 的终止条件

循环删除当前链表开头连续满足以下条件的结点：

p->utype == 1 && p->info.value == x

遇到子表结点，或者值不等于 x 的原子结点，都要停止当前连续删除循环。

示例：

原表：(x,(a,x,x),x,(x),b)
结果：((a),(),b)

7. 共享表与引用计数

  • 多个位置引用同一子表时，该子表需要引用计数。
  • 删除一次引用，先执行 ref--。
  • ref > 0：保留子表。
  • ref <= 0：真正释放子表结点。

8. 广义表结点释放顺序

  • 横向遍历当前表的结点。
  • 遇到子表结点，先递归释放子表。
  • 再删除当前子表结点。
  • 最后释放本表附加头结点。

例如：

主表：H -> A -> B -> E
                |
                G -> C -> D

删除顺序：

A -> C -> D -> G -> B -> E -> H

考前优先级

高优先级

  • 稀疏矩阵快速转置与双指针相加。
  • 特殊矩阵四种压缩存储公式。
  • 三对角矩阵、带状矩阵的正向与逆向映射。
  • 广义表的递归复制、深度计算、删除。
  • 字符串动态内存管理及自引用问题。

中优先级

  • 多维数组地址计算。
  • 正交链表结点结构。
  • 广义表表头、表尾、长度、深度。
  • BF 算法及复杂度。
  • 字符串运算符重载。

低优先级

  • 静态与动态数组定义。
  • 字符串基本库函数。
  • 稀疏因子计算。
  • 已掌握的 KMP。

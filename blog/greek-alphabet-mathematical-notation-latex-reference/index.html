二、希腊字母（Greek Alphabet）

希腊字母共 24 个，广泛应用于数学、物理学、概率论、统计学和机器学习。

说明：

  1. LaTeX 区分大小写，例如 \gamma 表示 γ，\Gamma 表示 Γ。
  2. 对于 Α、Β、Ε 等与拉丁大写字母形状相同的希腊字母，标准数学 LaTeX 通常直接使用 A、B、E 等。
  3. 标准数学 LaTeX 没有通用的 \omicron 命令，通常用 o 代替。
  4. IPA 表示英语读音，不是现代希腊语读音。

七、复杂公式排版

1. 分段函数

显示效果：

f(x)={x2,x≥0,−x,x<0.

Markdown 源码：

\[
f(x)=
\begin{cases}
x^2,&x\ge 0,\\
-x,&x<0.
\end{cases}
\]

其中：

  • cases：分段函数环境。
  • &：分隔表达式与条件。
  • \\：换行。

2. 多行公式对齐

显示效果：

(a+b)2=a2+2ab+b2=a(a+b)+b(a+b)=(a+b)(a+b)

Markdown 源码：

\[
\begin{aligned}
(a+b)^2
&=a^2+2ab+b^2\\
&=a(a+b)+b(a+b)\\
&=(a+b)(a+b)
\end{aligned}
\]

其中：

  • aligned：多行公式对齐环境。
  • &：决定对齐位置，通常放在等号前。
  • \\：换行。

十、Markdown 公式编写注意事项

  1. 行内公式使用 \(...\)，独立公式使用 \[...\]。
  2. 上下标包含多个字符时，应使用花括号，例如 x_{n+1}。
  3. LaTeX 命令区分大小写，例如 \omega 和 \Omega。
  4. 多行公式可使用 aligned 环境，分段函数可使用 cases 环境。
  5. 数学函数名称优先使用 \sin、\cos、\ln、\log、\exp 等命令，以获得规范的正体排版。
  6. 自定义数学运算符名称可以使用 \operatorname{}。
  7. 公式中需要插入普通文字时，使用 \text{}。
  8. Markdown 表格中的竖线 | 可能被解析为列分隔符，编写公式时建议使用 \mid、\lvert、\rvert 或相应的 LaTeX 命令。
  9. 不同 Markdown 编辑器支持的 LaTeX 命令可能存在差异，应以当前编辑器的 MathJax 或 KaTeX 支持情况为准。

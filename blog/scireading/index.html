科学史 - 分数构成

平时 40%

  • 只要不缺课（点名的时候到）
  • 如果缺课 3 次 —— 0 分

期末 60%

最后一次课。交一份读书报告 / 小论文

  • 内容：限制在科学技术史，不得写小说与诗歌。主要是指自然科学，不是社会科学。
  • 大于等于 3000字，上不封顶。
  • 纸质，打印上交。

insights from previous works :

  1. 一个人物：密立根 - 油滴实验 by someone in Xianlin Camus，关于科学史中的“欺诈”

  2. 13 级化学系某同学 《怀疑的化学家》 波意耳：波意耳到底怀疑了哪些内容？

  3. 学生物的，100 分

    etc.

要求：可靠，保证科学严谨。叙述，清晰简洁。

Ref :

[1] 雷·斯潘根贝格,黛安娜·莫泽. 科学的旅程(插图版)[M]. 郭奕玲,陈蓉霞,沈慧君,译. 北京:北京大学出版社,2008.

[2] 列奥那多与现代科学的诞生[M].

[3] 史蒂文·温伯格. 仰望苍穹：科学反击文化敌手[M]. 黄艳华,江向东,译. 上海:上海科技教育出版社,2004.

[4] 霍勒斯·弗里兰·贾德森. 大背叛：科学中的欺诈[M]. 张铁梅,徐国强,译. 北京:生活·读书·新知三联书店,2018.

  • 大于 5000 字
  • 以 Ref 为依据

  • 不得含有事实性、科学性错误
  • 自行寻找、安装（如到 github 上）有助于写作的 skills，如 humanize 类等
  • 用 latex 编码，要求排版合宜、高水准
  • 不得直接照搬 insights 中的内容

第三章：栈与队列

1. 栈（3.1）

基本概念

  • 栈（Stack）：只允许在一端插入、删除的线性表。
  • 栈顶（top）：允许插入、删除的一端；另一端为栈底（bottom）。
  • 后进先出（LIFO），也称先进后出（FILO）。
  • 基本操作：Push、Pop、getTop、IsEmpty、IsFull、getSize、makeEmpty。
  • 上溢（Overflow）：栈满时继续入栈；下溢（Underflow）：空栈出栈。
  • getTop 只读取，不删除；Pop 读取并删除。
  • 判断出栈序列是否合法：任意时刻出栈次数不能超过已入栈次数，且必须符合栈顶顺序。
  • n 个元素按固定顺序入栈，合法出栈序列数为 Catalan 数：
Cn=1n+1(2nn)

顺序栈（SeqStack）

设数组容量为 maxSize，top 指向当前栈顶元素。

项目 规则
初始化 top = -1
判空 top == -1
判满 top == maxSize - 1
入栈 elements[++top] = x
出栈 x = elements[top--]
取栈顶 x = elements[top]
元素数量 top + 1
清空 top = -1
  • Push、Pop、getTop、getSize：通常为 O(1)。
  • 固定容量时，栈满不能直接写入；动态扩容需重新分配并复制元素，单次扩容可能为 O(n)。
  • 按倍数扩容的顺序栈，入栈均摊复杂度为 O(1)。

双栈共享空间（DualStack）

两个栈分别从数组两端向中间增长。

项目 左栈 d=0 右栈 d=1
初始栈顶 t[0] = -1 t[1] = maxSize
入栈 a[++t[0]] = x a[--t[1]] = x
出栈 x = a[t[0]--] x = a[t[1]++]
判空 t[0] == -1 t[1] == maxSize
  • 共享空间满的条件： t[0] + 1 == t[1]。
  • 两个栈的可用空间动态共享，可减少空间浪费。
  • 基本入栈、出栈均为 O(1)。
  • 多于两个栈共享数组时，空间管理与元素移动更加复杂。

链式栈（LinkedStack）

  • 使用单链表，通常不带头结点，top 指向链头。
  • 空栈：top == nullptr。
  • 入栈：创建新结点，连接旧链头，更新 top。
  • 出栈：先保存数据与待删除结点，再更新 top，最后 delete。
  • 空间动态分配，无固定容量的栈满问题，但可能分配失败。
  • 适合元素数量变化较大、多栈操作等场景。
操作 不维护元素数量时的复杂度
Push O(1)
Pop O(1)
getTop O(1)
IsEmpty O(1)
getSize O(n)
makeEmpty / 析构 O(n)
  • 如果额外维护并正确更新计数器，getSize 可以为 O(1)。
  • 禁止访问已释放结点：x = p->data 必须在 delete p 之前完成。

栈的应用：括号匹配

  • 扫描到 (、[、{：入栈。
  • 扫描到 )、]、}：检查栈是否为空及栈顶类型是否匹配，匹配则出栈。
  • 非括号字符可以忽略。
  • 任一右括号无法匹配，立即判错。
  • 扫描结束后栈必须为空。
  • 时间 O(n)，辅助空间最坏 O(n)。

栈的应用：表达式

表示方式 示例 特点
前缀 Prefix +AB 运算符在操作数之前
中缀 Infix A+B 运算符在操作数之间
后缀 Postfix AB+ 运算符在操作数之后
  • 中缀表达式：乘除优先于加减；同级二元运算符按从左向右结合；括号最优先。
  • 前缀、后缀表达式的运算次序由符号位置确定，不再需要括号。
  • 例：A+B*(C-D)-E/F → ABCD-*+EF/-。

中缀表达式直接求值：

  • 使用两个栈：操作数栈 opnd、运算符栈 optr。
  • 遇操作数：压入 opnd。
  • 遇运算符：比较栈内、栈外优先级，决定入栈或计算。
  • 计算时弹出运算符，再弹出右操作数 b、左操作数 a，计算 a op b。
  • ( 入运算符栈，遇 ) 时计算并消去对应括号。
  • 课件使用 = 作为表达式起止标记。

课件给出的栈内、栈外优先级：

运算符 = ( * / + - )
栈内 isp 0 1 5 3 6
栈外 icp 0 6 4 2 1

中缀转后缀：

  • 使用运算符栈，操作数直接输出。
  • icp > isp：当前运算符入栈。
  • icp < isp：弹出栈顶运算符并输出，继续比较。
  • icp == isp：弹出但不输出，用于括号匹配和结束标记。
  • 普通同级左结合运算符要先弹出旧运算符。
  • 课件转换算法以 # 作为结束标记。

后缀表达式求值：

  • 使用一个操作数栈，从左向右扫描。
  • 遇操作数：入栈。
  • 遇运算符：先弹出右操作数 b，再弹出左操作数 a，计算结果入栈。
  • 扫描结束后，栈内应恰好留下一个结果。
  • 操作数不足、除数为 0、结果数量异常，均属于非法情况。
  • 例：12 6 2 / 0.5 - * → 30。
  • 例：8 2 3 - / → -8。
  • 时间复杂度 O(n)，辅助空间最坏 O(n)。

2. 栈与递归（3.2）

递归基本概念

  • 递归：函数直接或间接调用自身。
  • 常见情况：
    • 定义递归：阶乘。
    • 数据结构递归：链表。
    • 问题解法递归：汉诺塔。
  • 必须具有递归出口，子问题应逐步缩小并与原问题具有相同求解结构。
  • 递归过程包括递推（逐层调用）和回归（逆序返回）。
  • 递归工作栈保存各层活动记录：参数、局部变量、返回位置等。
  • 递归深度为 d、每层占常数空间时，工作栈空间为 O(d)。

典型递归

问题 递归关系 / 结果
阶乘 0!=1,n!=n(n−1)!
Fibonacci F0=0, F1=1, Fn=Fn−1+Fn−2
汉诺塔 H(n)=2H(n−1)+1=2n−1

汉诺塔：

  • 只能一次移动一个圆盘，大盘不能放在小盘上。
  • 先将 n−1 个盘子移至辅助柱，再移动最大盘，最后将 n−1 个盘子移至目标柱。
  • 最少移动次数：2n−1。
  • 时间复杂度：Θ(2n)；递归栈空间：O(n)。

递归与非递归

  • 递归改非递归的方法：
    • 迭代、循环：适合尾递归和可以直接维护状态的问题。
    • 显式栈：模拟递归工作记录与返回顺序。
  • 尾递归：递归调用是当前函数最后需要执行的操作，可在适当条件下改为循环。
  • 普通 Fibonacci 递归存在大量重复计算，时间为指数级；迭代实现时间 O(n)、额外空间 O(1)。
  • 课件给出的朴素 Fibonacci 递归调用次数：2Fn+1−1。
  • 大整数计算注意溢出：int 可正确表示的最大 Fibonacci 下标为 46；long long 为 92。
  • 算法题要求迭代时，递归版本即使数值正确，也不满足实现要求。

3. 队列（3.3）

基本概念

  • 队列（Queue）：队头删除、队尾插入的线性表。
  • 先进先出（FIFO）。
  • front 为队头，rear 为队尾。
  • 基本操作：EnQueue、DeQueue、getFront、IsEmpty、IsFull、getSize。

顺序队列与假溢出

  • 普通顺序队列中，队尾到达数组末端时，前部即使存在空闲位置，也可能无法继续入队，称为假溢出。
  • 循环队列通过取模实现数组首尾相接，避免假溢出。

循环队列（SeqQueue）

课件约定：front 指向队头元素，rear 指向下一个入队位置。

设数组长度为 maxSize，采用牺牲一个存储单元的实现。

项目 公式 / 操作
初始化 front = rear = 0
判空 front == rear
判满 (rear + 1) % maxSize == front
当前元素数 (rear - front + maxSize) % maxSize
最大有效元素数 maxSize - 1
入队 elements[rear] = x，再更新 rear
出队 x = elements[front]，再更新 front
取队头 x = elements[front]，不修改指针
清空 front = rear = 0

指针更新：

front = (front + 1) % maxSize;
rear = (rear + 1) % maxSize;
  • 基本入队、出队、取队头、求长度均为 O(1)。
  • 数组长度为 6 时，最多存放 5 个元素。
  • front == rear 表示空；不能同时使用该条件表示满。
  • front 和 rear 均可发生回绕，不能直接用 rear - front 计算长度。

链式队列（LinkedQueue）

  • 使用单链表，维护 front 和 rear 两个指针。
  • 课件使用不带头结点的实现。
  • 初始化：front = rear = nullptr。
  • 空队列：front == nullptr。
  • 入队：
    • 原队列为空：新结点同时成为 front、rear。
    • 原队列非空：连接到 rear->next，更新 rear。
  • 出队：保存队头数据，移动 front，删除旧队头。
  • 删除最后一个结点后必须将 front、rear 都置空，避免 rear 成为悬空指针。
  • 入队、出队、取队头均为 O(1)。
  • 不维护计数器时，getSize() 需要遍历，复杂度 O(n)。

队列应用：杨辉三角形

  • 每行首尾元素为 1。
  • 内部元素等于上一行相邻两个元素之和：
ai,j=ai−1,j−1+ai−1,j
  • 可使用队列逐行生成、打印杨辉三角形。
  • 课件队列算法通过加入 0 作为相邻行的边界辅助值。
  • 利用 s + t 计算下一行系数，其中 s 保存前一个出队元素，t 为当前出队元素。
  • 处理边界时有 0 + 1 = 1，便于统一计算。
  • 输出前 n 行总共有 n(n+1)2 个系数，时间复杂度 O(n2)。

4. 优先级队列（3.4）

基本概念

  • 每次出队的是优先权最高的元素，不一定是最早入队的元素。
  • 优先权大小由具体问题规定，数值大或数值小都可能表示高优先权。
  • 优先级相同时，课件规定按 FIFO 处理。
  • 典型应用：任务调度。

有序数组实现（课件 PQueue）

课件采用数值越小，优先级越高的约定。

  • pqelements[0]：优先权最高的元素。
  • count：当前元素数量。
  • Insert：插入并调整，使数组按优先级从小到大排列。
  • RemoveMin：删除优先级数值最小的元素。
  • getFront：读取 pqelements[0]。
  • 同优先级保持 FIFO：插入时只移动优先级严格大于新元素的旧元素。
操作 时间复杂度
有序数组插入 最坏 O(n)
读取最高优先级元素 O(1)
删除数组首元素并保持连续 O(n)
如果最高优先级元素放在数组末端，删除末尾 O(1)
  • 二分查找可以将定位插入位置降至 O(log⁡n)，但元素移动最坏仍为 O(n)。
  • 有序数组的插入、删除复杂度取决于最高优先级元素放在哪里。
  • 数组升序且最大值在末尾：插入 O(n)，删除最大值 O(1)。

二叉堆实现（课件知识导图提及）

  • 堆是满足堆序性质的完全二叉树。
  • 最小堆：父结点不大于子结点。
  • 最大堆：父结点不小于子结点。
  • 堆不要求数组整体有序，兄弟结点之间没有固定大小关系。
  • 从下标 0 开始存储时：
关系 下标
父结点 (i - 1) / 2
左子结点 2 * i + 1
右子结点 2 * i + 2
  • 插入：末尾插入，向上调整（sift up）。
  • 删除堆顶：末尾元素补到堆顶，向下调整（sift down）。
  • 最小堆下沉时应优先与两个子结点中的较小者比较。
  • 空堆删除应返回失败；删除唯一元素后不再进行下沉。
操作 时间复杂度
查看堆顶 O(1)
插入、向上调整 O(log⁡n)
删除堆顶、向下调整 O(log⁡n)
逐个插入建堆 O(nlog⁡n)
自底向上建堆 O(n)
  • 二叉堆通常不自动保证同优先级 FIFO；需要稳定性时，应额外保存入队序号用于比较。

5. 双端队列（3.5）

基本概念

  • 双端队列（Deque）：允许在队头、队尾两端插入和删除。
  • 栈与普通队列均可视为对双端队列操作的限制。
  • 基本操作：
    • EnQueueHead：队头插入。
    • EnQueueTail：队尾插入。
    • DeQueueHead：队头删除。
    • DeQueueTail：队尾删除。
    • getHead、getTail：读取两端元素。

循环数组实现（SeqDeque）

沿用循环队列的指针约定，front 指向首元素，rear 指向末元素的下一个位置。

设 n = maxSize。

操作 指针更新 / 取值
队头插入 front = (front - 1 + n) % n，然后写入
队尾插入 先写入，再令 rear = (rear + 1) % n
队头删除 先读取，再令 front = (front + 1) % n
队尾删除 先令 rear = (rear - 1 + n) % n，再读取
读取队头 a[front]
读取队尾 a[(rear - 1 + n) % n]
  • 判空：front == rear。
  • 判满：(rear + 1) % n == front。
  • 当前元素数：(rear - front + n) % n。
  • 最大元素数：n - 1。
  • 六个基本插入、删除、读取操作均为 O(1)。
  • 课件 SeqDeque 继承 SeqQueue，队尾入队、队头出队可直接复用普通队列操作。

数据结构 / 算法 关键复杂度
顺序栈入栈、出栈 O(1)，不计扩容
共享双栈入栈、出栈 O(1)
链式栈入栈、出栈 O(1)
链式栈遍历求长度 O(n)
循环队列入队、出队 O(1)
链式队列入队、出队 O(1)
链式队列遍历求长度 O(n)
有序数组优先级队列插入 O(n)
二叉堆插入、删除堆顶 O(log⁡n)
循环双端队列基本操作 O(1)
括号匹配、后缀求值 O(n)
杨辉三角前 n 行 O(n2)
汉诺塔 Θ(2n)
朴素递归 Fibonacci 指数级
迭代 Fibonacci O(n)

两个栈实现一个队列

  • 入队：元素压入 S1。
  • 出队：S2 非空时直接弹出；否则先将 S1 全部转移到 S2，再弹出。
  • 单次出队最坏 O(n)，均摊 O(1)。
  • 每个元素最多经历一次由 S1 到 S2 的转移。

7. 本次错题与易错点

链式栈复杂度（第 4、21、23、25、26 题）

必须区分：函数自身复杂度 × 实际调用次数。

链式栈不维护长度时：

  • Push()：Θ(1)。
  • Pop()：Θ(1)。
  • getSize()：对长度为 n 的栈为 Θ(n)。
情况 总时间复杂度
对固定长度 n 的栈调用一次 getSize() Θ(n)
固定长度 n，调用 n 次 getSize() Θ(n2)
每次 getSize() 后 Pop()，直至空栈 Θ(n2)
只调用一次 getSize()，随后执行 n 次 Pop() Θ(n)
固定长度 n，调用 ⌊log2⁡n⌋+1 次 getSize() Θ(nlog⁡n)
  • 第 21 题错误： 反复求长度、逐次出栈，正确复杂度为 Θ(n2)。
  • 第 23 题错误： 先求一次长度，再用计数器控制出栈，正确复杂度为 Θ(n)。
  • 第 25、26 题复测通过，仍需保持对调用次数的敏感度。

有序数组与堆复杂度（第 18、22 题）

  • 有序数组插入最坏 O(n)，不能因二分定位为 O(log⁡n) 就忽略元素移动。
  • 最高优先级元素在数组末尾时，删除为 O(1)。
  • 堆插入、删除堆顶最坏均为 O(log⁡n)。
  • 第 18 题错误；第 22 题复测通过。

循环队列、双端队列代码错误

C++ 运算符优先级：% 高于 +、-。

// 错误：取模只作用于 1
front = front + 1 % n;

// 正确
front = (front + 1) % n;

// 错误：可能产生负下标
front = front - 1 + n % n;

// 正确
front = (front - 1 + n) % n;
  • 减一回绕统一使用 (index - 1 + n) % n。
  • rear 指向下一次入队位置，读取队尾需要 rear - 1。
  • 不可在数组下标为负数或超过容量时访问元素。
  • 空队列、满队列必须在读写之前检查。
  • 队头插入和队尾插入都需要正确判满。
  • 原综合编程题中多次出现取模括号遗漏，最终已修正。

链表内存与边界错误

  • delete p 后不能再读取 p->data、p->next。
  • 链式队列删除唯一结点后，front 与 rear 均应为 nullptr。
  • 单结点、空结构、从空变非空、从非空变空均需单独检查。
  • 链式栈、链式队列如果不维护计数器，遍历求长度为 O(n)。
  • 析构链式结构时逐个释放结点，防止内存泄漏。

表达式与递归易错点

  • 后缀求值的弹栈顺序：先 b，后 a；计算 a - b、a / b。
  • 中缀转后缀：括号不输出；同优先级左结合运算符需要先输出旧运算符。
  • 括号匹配：遇右括号时先判空，最后检查栈是否为空。
  • 递归必须有出口，递归调用规模必须缩小。
  • Fibonacci 要求迭代时，不能使用双重递归代替。
  • long long 返回值不代表内部使用 int 计算就不会溢出。

Hot Keys

一、系统级快捷键

快捷键 作用
Cmd + Space 打开 Spotlight 搜索
Cmd + Tab 切换应用
Cmd + ~ 同一应用内切换窗口
Cmd + Q 退出当前应用
Cmd + W 关闭当前窗口或标签页
Cmd + H 隐藏当前应用
Cmd + M 最小化当前窗口
Cmd + , 打开当前应用设置
Cmd + Option + Esc 强制退出应用

二、文本编辑快捷键

快捷键 作用
Cmd + C 复制
Cmd + V 粘贴
Cmd + X 剪切
Cmd + Z 撤销
Cmd + Shift + Z 重做
Cmd + A 全选
Cmd + ← 跳到行首
Cmd + → 跳到行尾
Option + ← 向左按单词移动光标
Option + → 向右按单词移动光标
Cmd + Delete 删除光标前本行内容
Option + Delete 删除前一个单词

三、截图与录屏快捷键

快捷键 作用
Cmd + Shift + 3 全屏截图
Cmd + Shift + 4 选区截图
Cmd + Shift + 5 打开截图与录屏工具
Cmd + Shift + 4 后按 Space 截取指定窗口

四、浏览器与标签页快捷键

快捷键 作用
Cmd + T 新建标签页
Cmd + N 新建窗口
Cmd + Shift + N 新建无痕窗口
Cmd + L 聚焦地址栏
Cmd + R 刷新页面
Cmd + Shift + R 强制刷新页面
Cmd + 1–9 切换到第 1–9 个标签页
Cmd + Shift + [ 切换到左侧标签页
Cmd + Shift + ] 切换到右侧标签页
Cmd + W 关闭当前标签页

五、Finder 文件管理快捷键

快捷键 作用
Cmd + N 新建 Finder 窗口
Cmd + Shift + N 新建文件夹
Cmd + Delete 移到废纸篓
Cmd + I 查看文件信息
Space 快速预览文件
Cmd + ↑ 返回上级文件夹
Cmd + ↓ 打开文件或文件夹
Cmd + Shift + . 显示或隐藏隐藏文件

六、开发常用快捷键

快捷键 作用
Ctrl + C 终端中断当前程序
Ctrl + A 终端光标移动到行首
Ctrl + E 终端光标移动到行尾
Ctrl + U 删除当前命令行内容
Ctrl + L 清屏
Cmd + K 清空终端显示内容
Cmd + Option + I 打开浏览器开发者工具
